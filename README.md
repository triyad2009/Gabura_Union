# Gabura Digital Archive

Section 01 — GABURA

Next.js App Router foundation for an independent evidence/archive platform documenting Gabura, Shyamnagar, Satkhira.

## Run

npm install
npm run dev

## Routes

/ — archive home
/gabura — Section 01 hub
/gabura/about
/gabura/history
/gabura/origin-of-name
/gabura/geography
/gabura/rivers-and-waterways
/gabura/villages-and-mouzas
/gabura/population
/gabura/administration
/gabura/maps
/gabura/timeline

Content that is not yet source-verified is deliberately framed as local tradition or planned research, not established fact.
